A zero-database, privacy-first contact form plugin with built-in anti-spam.

== Description ==
Clean Contact Form sends incoming messages directly to your inbox without saving entries to the database.

== Installation ==
1. Upload the plugin files to `/wp-content/plugins/clean-contact-form`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Add `[clean_contact_form]` to any page or use the Gutenberg widget.
